# Seasonal Protocol Data

This directory stores protocol-specific assets for the six-client seasonal scarcity experiment.

Expected generated files:

- `58wf_seasonal_protocol.mat`
- `59wf_seasonal_protocol.mat`
- `60wf_seasonal_protocol.mat`
- `61wf_seasonal_protocol.mat`
- `62wf_seasonal_protocol.mat`
- `63wf_seasonal_protocol.mat`
- `seasonal_protocol_metadata.json`

These assets are generated by `build_six_client_seasonal_protocol.py` from the raw `2223jilin_*_processed_4classes.xlsx` and `24jilin_*_processed_4classes.xlsx` workbooks.

Launcher usage:

- Full sequential run:
  - `python run_six_client_seasonal_protocol.py all`
- Rebuild assets only:
  - `python run_six_client_seasonal_protocol.py build`
- Training only with seasonal preset:
  - `python run_six_client_seasonal_protocol.py train`
- Evaluation only with seasonal preset:
  - `python run_six_client_seasonal_protocol.py eval`
- Smoke dry-run without starting long training:
  - `python run_six_client_seasonal_protocol.py all --smoke --dry-run`
- Formal seasonal run with the current default paper budget:
  - `python run_six_client_seasonal_protocol.py all --preset formal-v1`
